## 💻 Tech Stack

Built with simplicity in mind:

- **Static Site** — Fast, secure, and easy to deploy
- **GitHub Pages** — Free hosting with built-in CI/CD
- **Jekyll** — The world's fastest website builder
- **Minimal** — No bloat, just content

---

## 🎯 Why This Approach?

> "Make it simple first. Complicate it later if you need to."

Static sites are:
- ✅ Blazing fast (no server-side processing)
- ✅ Secure by default (no database, no auth to hack)
- ✅ Easy to scale (just throw more bandwidth at it)
- ✅ Free to host (GitHub Pages + Netlify + Vercel all work)
